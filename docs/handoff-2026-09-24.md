## 发布方式

阅读 `AGENTS.md` 与 `docs/cloudflare-deployment.md`。构建命令为 `npm run build:static`，输出 `dist`。当前 Cloudflare Pages 项目名 `jk-ielts-reading`，采用 Direct Upload，不会随 Git push 自动发布。提交并推送源码后再构建，保持许可证页与 build-info 的源码版本一致。

Cloudflare 登录保存在用户 Chrome。上传 709 个文件，约 244 MB（主要是 PDF）；压缩包约 214 MB。控制台刚选择 ZIP 时可能短暂显示 25 MiB 错误，解压完成后会变成 709 个文件并成功上传，勿过早取消。

浏览器扩展 setFiles 被文件权限拒绝，而且可能长时间阻塞。已成功的替代方式是原生 Chrome 窗口的文件选择器：先用“窗口”菜单选中 IELTS 工作窗口，再选 Cloudflare 标签页，原生点击 file，Cmd+Shift+G 输入 ZIP 路径，选择并打开。不要只在后台通过 Playwright 点击 file 后假定原生选择器已打开。不要自行修改扩展权限。

PWA 会缓存旧版；发布后等“发现新版本”，点击“立即更新”。无需清除用户答题记录。

临时发布包 `/private/tmp/jk-ielts-reading-ui.zip`，仅作临时产物，不能依赖长期存在。重新发布应按当前提交重新构建。
